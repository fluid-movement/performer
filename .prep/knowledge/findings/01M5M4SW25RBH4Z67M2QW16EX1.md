## Recommended structure

Entry: AGENTS.md (CLAUDE.md in older checkouts) points to agent-docs/index.md. The index routes by kind of change (engine, stored field, Steps page, config page, routing, clock, tests, UI design) to ONE feature doc, which holds how it works, where the code lives and a Change Guide, and links to prep decisions by `prep knowledge find <word>` instead of restating reasons. Keep one doc per track type and per subsystem: agents load only the doc for their area, and merging would cost tokens on every task. Added testing.md (the harness is needed for every engine change) and features/config-pages.md (the modeless ListPage system had no doc, only history). architecture.md stays as the layer/task/tick overview. All docs use full repo paths in code spans so a script can check them.

Why agents were misled before: the docs were written once and never swept. Accuracy audit found stale or wrong content in nearly every doc: stochastic (pre-V2 model), logic-track (deleted), serialization (claimed a tag format; code is positional with version-gated reads and a trailing hash), quantizer (Internal mode, LogicTrackEngine, reader.dataVersionAtLeast), arp (play mode, CONV/DIV "not implemented", CONTEXT.md refs), curve (fields that do not exist, removed fill mode, moved sandbox path), midicv (invented fields), clock-sync (invented ClockSetup fields), cv-io (claimed input calibration and a moving average that do not exist), routing and midi-io (wrong source types and event names), scales (BypassScale, per-sequence scale), patterns-projects (LogicTrack, PlayState "not serialized", user scales owned by Project), launchpad (wrong file names), ui-system (LogicSequencePage). Also architecture claimed clock IRQ calls track ticks; ticks are queued and drained by the engine task.

## Keeping docs current

1. scripts/check-agent-docs.py (`just docs-check`): fails on dead markdown links, dead code paths in code spans and docs not linked from index.md. Cheap enough to run on every docs change.
2. AGENTS.md/CLAUDE.md states the rule: a change that alters behaviour, file locations or a stored format updates the matching doc in the same change.
3. Wanted but blocked for this agent (permission denied): a Definition of Done item via `prep dod --add`, and removing the stale hooks in .claude/settings.json that still tell sessions to update the retired CONTEXT.md (PreCompact and Stop). Suggested DoD text: "If the change alters behaviour, file locations or a stored format, the matching doc in agent-docs/ is updated and `just docs-check` passes." Suggested Stop hook: remind when src/ changed to update agent-docs and run docs-check.
4. Docs describe the present; reasons are prep decisions; history is git and features-log.
