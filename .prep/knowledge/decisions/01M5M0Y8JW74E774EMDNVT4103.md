title: Note engine is a slot scheduler with onsets derived from the step start
description: A step is repeat*retrigger slots scheduled one at a time; beginStep latches per-step decisions at slot 0; slotOnset(k) = _stepStartTick + _stepTotalTicks*k/_totalSlots, never accumulated, so rounding stays bounded and the last slot lands on the step end. Each slot pushes at most 2 gate + 1 CV event. In Retrigger gate mode gate-off is clamped to slotLen-1 so it never coincides with the next gate-on. The slide flag rides only on slot 0, so intra-step arp jumps snap. A gate-off step pushes nothing and changes no CV.
